Component specification

Components, variants and states for the SCASPA Assistant

Every control the assistant can render, drawn at full size on the dark surface it ships on. The product has two data paths that must never look alike — model prose and the operations feed — and the whole system is built around telling them apart. Seven components are marked blocked; each names the field the backend must return before it can ship.

Two data paths — the rule the whole system is built on

The meta strip is the tell. If a block has one, a feed produced it. If it has none, a model wrote it.

Assistant path · /api/chat · no container

Wharfage on a 40ft import container is charged at XCD 186.00 per container per call kb-014. I cannot see live vessel movements, so I cannot tell you whether a particular ship has berthed kb-002.

No card. No border. No meta strip. No timestamp.

Prose sits flush on surface-1 and carries citations, nothing else. It is never given a card, because a card in this product is a claim of provenance and a model cannot make one. The dashed outline above is board annotation only — it does not ship.

Every operations payload carries a DataSource object, so every operations block carries a meta strip: source-kind badge, label, as_of. When kind is fixture or unavailable the notice below it is schema-required and non-dismissible.

The two blocks above will regularly appear one under the other in the same turn — prose saying "I cannot see live movements" directly above a board of movements. That is correct behaviour, not a contradiction, and the layout must never imply the prose is summarising the rows. They are separated by 24px, the prose never sits inside the card, and the card's meta strip states its own source independently.

Why unknown is drawn, not guessed

Unknown is a real value and it means the record has no status — not that the vessel is late, and not that it is fine. It gets a hollow dot, an em dash where a value would be, a dashed outline instead of a fill, and no status hue at all. Rendering it as "Expected" or leaving the cell blank would both be inventions.

Three of the nine values never appear in current test data. They are drawn here at full fidelity because production will produce them, and a chip that has never been rendered is a chip nobody has checked.
